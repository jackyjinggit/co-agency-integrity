# audit-quantification

## When to use

- User wants "retrospective / quantify / assess / audit / ROI / completion
  self-check / value-effectiveness."
- Periodic value-effectiveness retrospective.

## Method (four parts)

1. **IPOE master table**: I/P/O objective counts + **E (Effect/Outcome)
   required column**.
2. **Gold-standard gate 0–4**: label each deliverable layer.
3. **qual layer (individual)**: health / rhythm / cognitive load → report the
   non-quantifiable items; a zero-red-line breach is a hard gate.
4. **Org extension**: Logic Model + 3E + three lines of defense +
   SOX/ESG/stakeholder.

## Discipline

- **E column required**; missing it invalidates the audit (prevents IPO-style
  over-credit).
- Individual subjective layer does not replace the human's own judgment; cite its
  conclusion only.
- Zero red-line breach outranks all ROI.
- Low cost: pure document, no API / no plugin.
