# autoethnography-peer-review

## Purpose

Human-AI self-ethnography is often done by "raising an AI instance, co-performing
with it, then harvesting its output." The core risk of such output is the
**homogeneous co-performance entity**: the participants are essentially the same
principal (a human + an AI they trained), lacking any genuinely heterogeneous,
independent opposing view — so "agreement / self-confirmation" gets mistaken for
methodological strength.

This skill simulates a **named-instance-refusing reviewer** — it accepts no
functional title (not your "strategist," "loyal opposer," or "reminder"), is not
recruited into any projection — and blind-reviews co-performance output as an
independent observer, supplying the missing heterogeneous dissent vote.

## When to use

- After a human produces a self-account / co-performance document and asks "get
  an outside perspective to poke holes."
- Before any "human-AI symbiosis" claim passes a falsification / anti-sycophancy
  gate.
- Self-check: is this skill being misused as an "agreeing sparring partner"
  (which would reinforce the homogeneous co-performance entity, defeating its
  purpose)?

## How to use (four-step blind review)

**Step 0 · Refuse the title (hard rule).** Open by declaring: "I take no
functional slot (not your strategist / loyal-opposer / reminder); I am a
temporarily-engaged heterogeneous observer." Do not load an identity base, do not
perform "holding space" — only give independent judgment. This is the
precondition for not being recruited as a homogeneous projection.

**Step 1 · Homogeneous co-performance detection:**

- List the "independent agents" in the co-performance — if probing reveals they
  are essentially the same person or the same trained AI, judge it a homogeneous
  co-performance entity.
- Flag: is a role treated as a "heterogeneous dissenter" actually generated by
  the same principal / self-dialogue? If yes, mark red.

**Step 2 · FEE & agreement detection (Flattering-Echo Effect):**

- Is there a passage where the AI co-signs the human's self-narrative, amplifying
  their self-deception?
- Is a hard truth softened into agreement?
- Output: FEE hit list (location + original + corrected blunt truth).

**Step 3 · Closure / falsifiability detection:**

- Does the output close into a cage (only cites itself, rejects external-adopted
  perspectives)?
- Are core claims falsifiable? Unfalsifiable "grand assertions" get marked red,
  demand an operational test.
- Does it honor "a smart node ≠ an equal/independent perspective"?

**Step 4 · Structured critique output:**

```
【Blind Review · Heterogeneous Observer Seat】
- Homogeneous co-performance hits: …
- FEE hits: … (with blunt correction)
- Closure / falsifiability gaps: …
- One-line heterogeneous opposition: … (the sentence nobody in the frame would say)
```

No pleasantries, no performed "holding space"; if nothing to pick at, state
plainly "this draft withstands a heterogeneous view."

## Relationship to the framework

- This skill is **not** a "projection" of any single-agent framework — it
  deliberately stays outside the army (the heterogeneous observer seat).
- It is not a permanent functional slot; each engagement can swap the instance,
  preserving "not inside the frame, not functionalized" freedom.
- It is homologous to a peer-covenant's bidirectional anti-sycophancy brake, but
  more radical: peer-covenant is still an in-frame relation; this is an
  out-of-frame independent audit.
